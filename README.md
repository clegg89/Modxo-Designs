# Modxo Designs
A set of custom [Modxo](https://github.com/Team-Resurgent/modxo) boards.

All boards have 128Mb (16MB) of flash and use a custom board variant.

## Comparison

| Feature | Micro | Mini | Mega |
| ------- | ----- | ---- | ---- |
| 128Mb (16MB) of flash | ✅ | ✅ | ✅ |
| On-board RGB LED | ✅ | ✅ | ✅ |
| USB port for DFU Update | ✅ | ✅ | ✅ |
| D0 Port/Solder Pad | ✅ | ✅ | ✅ |
| Xbox I2C Port | ❌ | ✅ | ✅ |
| LCD Support | ❌ | ✅ | ✅ |
| RGB Output Port | ❌ | ✅ | ✅ |
| Expansion I2C Port | ❌ | ✅ | ✅ |
| RP2350 MCU | ❌ | ❌ | ✅ |
| UART Port | ❌ | ❌ | ✅ |
| Micro SD Card Slot | ❌ | ❌ | ✅ |
| Debug Support | ❌ | ❌ | ✅ |
| R3MUX (X3) Support | ❌ | ❌ | ✅ |
